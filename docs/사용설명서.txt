메신저 동기화 (시험 버전 v0.1.6) 사용설명서
==================================================

■ 들어 있는 파일
  - MessengerSync.exe   : 프로그램 (이 파일 하나만 있으면 됩니다. .NET 설치 필요 없음)
  - 사용설명서.txt      : 이 문서

  ※ 구글 설정 때 받은 client_secret.json 을 exe와 같은 폴더에 함께 두어야 합니다.


■ 1. 시험 전에 꼭 할 것 (안전장치)
  1) 메신저를 완전히 종료합니다 (트레이 아이콘 → 종료).
  2) 쪽지 폴더의 SN200662.db 를 바탕화면 등 다른 곳에 복사해 둡니다.
     (쪽지 폴더 위치 예: C:\Users\사용자이름\AppData\Local\UlsanEdu Messenger\history)
  3) FreeFileSync 동기화는 더 이상 실행하지 않습니다.
     두 프로그램이 같은 파일을 건드리면 꼬입니다.
  4) 메신저 자체의 "윈도우 시작 시 자동 실행"이 켜져 있다면 끕니다.
     (켜져 있어도 이 프로그램이 감지해서 "끄고 동기화할까요?"라고 묻긴 합니다.)


■ 새 버전으로 바꿀 때 (v0.1.5부터)
  - 트레이 아이콘 오른쪽 클릭 → [업데이트 확인]
    새 버전이 있으면 바뀐 점을 보여주고, [지금 업데이트]를 누르면
    받기 → 파일 확인 → 교체 → 다시 시작까지 자동으로 합니다. (설정과 로그인은 그대로)
  - 하루 한 번 자동으로 확인해서, 새 버전이 있으면 알림을 띄웁니다.
    이때 메뉴가 [업데이트 설치 (v0.x.x)]로 바뀝니다.
  - 메신저가 켜져 있으면 먼저 종료·업로드하고, 업데이트 후 다시 켭니다.
  - 새 버전은 https://github.com/xleesjx/messenger-sync/releases 에서 받습니다.
    받은 파일의 해시값이 맞지 않으면 업데이트하지 않습니다.

  v0.1.4 이하에서 처음 넘어올 때만 직접 바꿉니다:
  1) 트레이 아이콘 오른쪽 클릭 → [프로그램 종료]
  2) C:\MessengerSync\MessengerSync.exe 를 새 파일로 덮어쓰기
  3) MessengerSync.exe 다시 실행


■ 2. 설치 (PC마다 한 번)
  1) C:\MessengerSync 폴더를 만들고 다음 두 파일을 넣습니다.
       - MessengerSync.exe
       - client_secret.json  (G:\내 드라이브\00 dev\03_messenger\program\ 에 넣어 둔 파일)
     ※ G: 드라이브에서 바로 실행하지 마세요. 부팅 직후에는 G: 드라이브가 아직 준비되지 않아
       자동 실행이 실패할 수 있습니다. 반드시 C: 로 복사해서 실행하세요.
  2) MessengerSync.exe 를 실행합니다.
     "Windows의 PC 보호" 창이 뜨면 → [추가 정보] → [실행] 을 누릅니다.
     (코드서명 인증서가 없어서 처음 한 번 뜨는 경고입니다.)
  3) 설정 화면이 뜹니다. 아래 3번대로 입력합니다.


■ 3. 설정 화면
  [쪽지 파일]
    - 아이디        : SN200662   → 아래에 "✔ SN200662.db 있음"이 보이면 정상
    - 쪽지 폴더     : [자동 찾기]를 누르면 대부분 자동으로 채워집니다
    - 메신저 실행파일: C:\Program Files (x86)\UlsanEdu Messenger\TUC.exe (기본값)
    - 프로세스 이름 : TUC (기본값)
    - 이 PC 이름    : 창의센터 / 교수부 / 노트북 중 선택

  [클라우드 저장 방식]
    - "구글 드라이브 API" 선택
    - client_secret.json : exe 옆에 두었다면 그대로 두면 됩니다
    - 구글 계정(선택)    : 학교 구글 계정 주소  (로그인 창에서 이 계정이 먼저 선택됩니다)
    - [구글 로그인] 버튼 → 브라우저가 열리면 학교 계정 선택 → "Google에서 확인하지 않은 앱"
      안내가 나오면 [계속] → 권한 [허용]
      → "학교 구글 드라이브에 접근할 수 있습니다" 창이 뜨면 성공입니다.
      ※ "액세스 차단됨" 같은 오류가 나오면 학교 관리자가 막은 것입니다. 오류 화면을 캡처해 주세요.
        이 경우 "폴더 지정" 방식으로 바꿔서 G:\내 드라이브\00 dev\03_messenger 를 지정하면 됩니다.

  [자동 동작] (기본값 그대로 추천)
    - 화면 잠금(Win+L) 시 메신저를 끄고 업로드
    - 잠금 해제 시 최신 데이터를 확인하고 메신저 다시 실행
    - 이 프로그램이 시작될 때 메신저도 실행
    - 클라우드가 더 새로우면 받기 전에 묻기
    - 윈도우 시작 시 이 프로그램 실행  ← 체크하세요

  [시험] → 아래 4번 참고

  [저장]을 누르면 바로 첫 동기화가 시작되고 메신저가 켜집니다.


■ 4. 메신저 종료 방식
  울산교육메신저는 X 버튼이 트레이로 숨기기만 하고, 다른 프로그램이 보내는 종료 신호에도
  반응하지 않습니다 (v0.1.0~0.1.2 시험으로 확인). 그래서 이 프로그램은 메신저를 강제 종료한 뒤,
  업로드하기 전에 쪽지 파일 정밀 검사를 합니다. 검사에 통과한 파일만 올립니다.
  (종료 3초 정도 + 검사 1초 미만)

  설정 화면의 [메신저 종료 시험]은 문제가 생겼을 때 진단용으로 남겨 두었습니다.


■ 5. 구글 드라이브 폴더 위치
  첫 로그인 때 "내 드라이브\messenger-sync-data" 폴더가 만들어집니다.
  원하면 구글 드라이브(웹 또는 G: 드라이브)에서 이 폴더를 통째로
  "00 dev\03_messenger" 안으로 옮겨도 됩니다. 옮긴 뒤에도 프로그램이 찾아냅니다.
  ※ 이 폴더 안의 파일을 직접 열거나 고치지 마세요.

  폴더 구조:
    messenger-sync-data\SN200662\current.json   ← 최신 버전 정보 (어느 PC, 언제)
                                  lock.json      ← 지금 사용 중인 PC
                                  devices.json   ← PC별 마지막 동기화 기록
                                  versions\v0001_20261104-1802_창의센터.db.gz ...
    보관 규칙: 최근 20개 + 그 이전 30일은 날짜마다 1개씩 (그날 마지막 버전)
    ※ 메신저는 로그인만 해도 파일이 바뀌어서, 잠글 때마다 새 버전이 생깁니다.


■ 6. 시험 순서 (추천)
  1) 최신 쪽지가 있는 PC(예: 창의센터)에서 먼저 설치·설정 → 첫 업로드(v1)
  2) 그 PC에서 Win+L → 잠시 후 잠금 해제 → 메신저가 다시 켜지는지 확인
  3) 다른 PC(교수부)에서 설치·설정 → "이 PC에서 처음 동기화합니다" 창에서
     [클라우드 사용 (창의센터)] 선택 → 쪽지가 창의센터와 같은지 확인
     (원래 교수부 파일은 보관 폴더 conflicts 에 남습니다)
  4) 교수부에서 쪽지를 주고받고 Win+L → 창의센터에서 잠금 해제 →
     "최신 쪽지 데이터가 있습니다" → [받고 시작] → 교수부 쪽지가 보이는지 확인


■ 7. 평소 사용법
  - 자리를 뜰 때: Win+L  → 메신저가 꺼지고 자동 업로드
  - 돌아왔을 때 : 잠금 해제 → 최신 확인 후 메신저가 자동으로 켜짐
  - 퇴근할 때  : Win+L 하고 PC를 켜 둔 채로 두면 가장 안전합니다
  - 노트북     : 덮개를 닫으면 절전되어 업로드할 시간이 없습니다. 덮기 전에 Win+L 을 누르세요.

  트레이 아이콘(초록 동그라미 화살표) 메뉴
    - 메신저 실행 (동기화 후) : 동기화를 거쳐 메신저 실행 (아이콘 더블클릭과 같음)
    - 메신저 종료 후 업로드   : 메신저를 끄고 바로 업로드
    - 지금 동기화             : 올리기 + 받기를 한 번에
    - 상태 / 버전 목록        : PC별 기록, 보관된 버전, 예전 버전으로 되돌리기
    - 설정 / 기록 폴더 열기
    - 자동 동기화 일시 중지   : 잠금/해제 때 자동 동작을 잠시 끔
  아이콘 색: 초록=정상, 파랑=동기화 중, 빨강=확인 필요(업로드 대기 등), 회색=일시 중지

  진행 창 (화면 오른쪽 아래)
    받기·실행:  클라우드 확인 → 쪽지 파일 비교 → 동기화(받기/올리기) → 메신저 실행
    업로드:     메신저 종료 → 쪽지 파일 검사 → 압축 → 업로드 → 마무리
    ✔ 완료  ▶ 진행 중(진행률 %)  ○ 대기  – 건너뜀(변경 없음 등)  ✖ 실패
    끝나면 결과를 1.5초(실패 시 5초) 보여주고 닫힙니다.

  바탕화면의 메신저 바로가기 대신 MessengerSync.exe 바로가기를 쓰면 좋습니다.
  (이미 트레이에 떠 있으면 "동기화 후 메신저 실행"으로 동작합니다.)


■ 8. 알아둘 점
  - 구글 로그인은 7일마다 다시 해야 합니다 (테스트 모드 앱).
    6일이 지나면 잠금 해제·실행 때 "로그인 갱신 시기입니다" 창이 뜹니다. [지금 갱신] → 브라우저에서 계정 선택.
  - 두 PC 모두에서 쪽지가 바뀌면 "두 곳 모두 쪽지가 바뀌었습니다" 창이 뜹니다.
    내용을 합치지는 못하고 한쪽을 고릅니다. 고르지 않은 쪽은 conflicts 폴더에 보관됩니다.
  - 다른 PC가 "사용 중"으로 표시되어 있으면 경고가 뜹니다. 그 PC에서 Win+L 을 안 했을 수 있습니다.
  - 업로드가 실패하면(인터넷 끊김 등) 트레이 아이콘이 빨갛게 되고 5분마다 다시 시도합니다.
  - 업로드 전에 쪽지 파일 손상 검사를 해서, 깨진 파일은 올리지 않습니다.
  - 윈도우 종료 버튼 처리, 자리 비움(입력 없음 N분) 감지는 다음 버전에서 추가됩니다.

  이 PC의 프로그램 파일 위치: %LOCALAPPDATA%\MessengerSync
    settings.json       설정
    backup\             덮어쓰기·업로드 전 로컬 백업 (최근 10개)
    conflicts\          충돌 때 고르지 않은 쪽
    logs\sync-YYYYMM.log 동작 기록  ← 문제가 생기면 이 파일을 보내 주세요
    token\              구글 로그인 정보 (윈도우 계정으로 암호화)


■ 9. 문제가 생기면
  - 오류 창 캡처 + logs 폴더의 sync-YYYYMM.log 파일을 보내 주세요.
  - 쪽지가 이상하면: 메신저를 끄고, 1번에서 복사해 둔 SN200662.db 나 backup 폴더의 파일을
    쪽지 폴더에 SN200662.db 이름으로 다시 넣으면 원래대로 돌아갑니다.
